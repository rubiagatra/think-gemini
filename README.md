# Think Like a Senior Developer

This repository is a collection of examples and guides to help you adopt the mindset of a senior developer. It focuses on writing robust, well-tested, and maintainable code in Python.

## What's Inside?

This repository provides practical examples to illustrate key concepts in software development.

### Topics Covered

*   **Problem Analysis**: Breaking down problems before writing code.
*   **Input Validation**: Handling invalid inputs gracefully.
*   **Testing**: Writing unit tests with `pytest` to ensure your code is reliable.
*   **API Development**: Building a simple REST API with FastAPI.
*   **Using AI in Development**: Leveraging AI tools like Gemini to improve your code and workflow.

## How to Use This Repository

1.  **Explore the Examples**:
    *   [`seniors.md`](seniors.md): A step-by-step guide to writing a robust function, from initial thought process to testing.
    *   [`think-gemini.md`](think-gemini.md): An example of building a FastAPI application and using AI to improve it.

2.  **Run the Code**:
    The examples include instructions on how to run the code and tests. You'll need Python and `uv` installed.
